# Yoru Tomosu companion — private development slice

Independent bottom-screen Log, Option and unlocked CG viewer. Log uses the game's retained history and speaker fields, excludes the current utterance and displays newest past dialogue first; loading a save follows the native history reset. Option holds scroll-speed (Slow/Normal/Fast) and Follow-newest (On/Off) controls plus the installed English patch's two Switch controller diagrams. CG uses a vertically scrolling 2x2 grid and opens known-unlocked art full screen. No guest inputs, guest calls or game-memory writes are sent.

The native module reads effective RomFS artwork/font from the player's game and existing patch; no game assets or translations are bundled. Supported input currently: title0100C2901153C000, base1.0.0 build3A573656D869F5786166FCFF376C93AE434C2B38000000000000000000000000. Other builds refuse. Latest official update/DLC and Japanese fallback remain unverified.

The Log scrolls by drag and fling on a native scrollable region with its own draggable scrollbar; "Latest"/"Oldest" taps at the scrollbar's ends jump straight there. Text-size -/+ controls sit in the Log's own header (hold to reset) and stay in sync with Option's copy. Option's scroll-speed and Follow-newest choices apply to both the Log and the CG grid; its controller-manual diagrams change by tapping either half or by a horizontal swipe. Pinch-to-zoom on the Log was tried and dropped (the runtime gives any pinch-capable widget the whole one-finger gesture before native scrolling is ever consulted). The CG grid scrolls the same drag/fling way; tap an unlocked thumbnail for full screen, then tap to return to the same grid. Desktop touch validation is recorded in the private prototype checkpoint and the 2026-10-16 live sessions; handheld gesture delivery and readability remain pending owner confirmation. Replay icons are informational; audio replay is not implemented.

This is a development package, not a published or fully tested release. Linux x86_64 and Android arm64 libraries build successfully; Android runtime/device verification remains pending. Build from native/modules target dsmod-yoru, generate manifest with tools/yoru-tomosu/gen_manifest.py, package using tools/build_dualscreen_package.py. Extracted resources, saves, screenshots and research remain private and outside this source package.
