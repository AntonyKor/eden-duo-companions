VAllhalla 1.0.0 - a dual-screen companion for VA-11 Hall-A (Nintendo Switch, title 010086500D3C8000,
base game v0) on Eden Duo.

Made by
  Mati            design, art and testing
  Code            written with Mati using an AI coding assistant

Runs on
  Eden Duo by igawa6, the dual-screen fork of the Eden emulator (1.3.0 or newer)

The game
  VA-11 Hall-A: Cyberpunk Bartender Action by Sukeban Games, published by Ysbryd Games.
  This package contains nothing from the game. Every game sprite (Jill, the cans, the shaker, the
  drinks, the cells, the title screen and break pictures, the doodles...), the game's sounds and its dialogue text are read
  at runtime from the player's own copy of the game. You need to own the game to use this.

In this package
  Original art by Mati: the SUCCESS popup, the error windows and their glitch frames, the
  tutorial hand and filters, the heart and the drawing in the little note under Age.
  Generated by the project's own tools: the bar window, the counter and Jill's shadow, the neon
  layers, the dust specks, the pixel dissolve, the drink bubbles.
  PixelMplus12 font by itouhiro, from M+ FONTS (M+ FONT LICENSE, see LICENSE-PixelMplus.txt).
